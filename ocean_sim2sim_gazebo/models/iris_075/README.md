# iris_075: 3DR Iris scaled 0.75 (drone to grasp)

## Source of the meshes

`meshes/iris.stl`, `meshes/iris_prop_ccw.dae`, `meshes/iris_prop_cw.dae` are copied unchanged from the
3DR Iris model of PX4 Gazebo-classic:

- repository: https://github.com/PX4/PX4-SITL_gazebo-classic, `models/iris/meshes/`,
  commit `70683dc759cbd3ebccfa78429b564f8b1fb5d149` (as a submodule of PX4-Autopilot v1.16)
- authors: Lorenz Meier and Thomas Gubler (`models/iris/model.config`)
- license: the repository declares `BSD` in its `package.xml` but has no LICENSE file. PX4 is licensed under
  BSD 3-Clause; its license text is included here as `LICENSE_PX4` (PX4-Autopilot).
- the Isaac Sim drone (Pegasus Simulator Iris, BSD 3-Clause) is the same mesh (18,171 vertices) turned 180 deg about z.

The PX4 meshes are no longer used by `model.sdf` (kept for `collision.source: coacd` and reference): the model now
uses the Isaac Sim (Pegasus Iris, BSD 3-Clause) meshes exported from Isaac Sim, see below.

## Exported from Isaac Sim (do not edit)

`ocean_sim2sim_gazebo/scripts/export_isaac_drone_collision.py` (Isaac Sim Python, the Isaac Sim project's own drone
loader) writes:

- `meshes/collision_isaac/`: PhysX cooked convex hulls of the body (`hull_*.stl`, body frame) and of the props
  (`rotorN_hull_*.stl`, rotor link frames), `isaac_flight.yaml` (whole-drone mass properties + thrust model, and
  `links:` = PhysX mass / COM / inertia per rigid body and the rotor link poses in the body frame), `report.txt`
- `meshes/visual_isaac/`: every visual mesh as OBJ (positions + normals) in its rigid-body link frame (body, red grasp
  tape left / right, 4 props) and `materials.yaml` (bound materials with all authored shader inputs; unbound meshes:
  what Isaac Sim renders)

## Generated files (do not edit)

`model.sdf` and `meshes/collision/hull_*.stl` are generated by `ocean_sim2sim_gazebo/scripts/build_iris_drone.py`
from `ocean_sim2sim_gazebo/config/iris_drone.yaml` and the Isaac Sim exports above (needs `pip install trimesh scipy pyyaml`):

- 5 links like Isaac Sim: `body` (0.78 kg) + `rotor0..3` (props, 0.005 kg each) on revolute joints `rotorN_joint`
  about the thrust axis (speed set by the DroneLockstep plugin: Isaac Sim prop spin rule, 0 = held)
- mass properties per link = Isaac Sim PhysX values (sum: 0.8 kg, COM and inertia = `isaac_flight.yaml` whole drone)
- collision: Isaac Sim PhysX hulls (body 32, one per prop), friction 0.6, contact sensors -> `/drone/contacts`
- visual: Isaac Sim meshes with one plain color per Isaac Sim material (no textures, see `config/iris_drone.yaml`)
